## About me

我是一名关注移动端、AI 产品与 Agent 工程的开发者。喜欢把复杂流程做成清晰、稳定、真正可用的工具：从移动端体验与自动化，到本地优先的 AI 工作流，再到浏览器实时交互与 macOS 原生效率工具。

- 📱 关注移动端架构、体验、工程质量与交付效率
- 🤖 使用 AI Agent 参与需求拆解、开发、验证和知识沉淀
- 🧰 偏爱 local-first、可观察、可测试、可持续演进的工具
- 🌱 **Be better every day** — 用持续的小改进积累长期复利
